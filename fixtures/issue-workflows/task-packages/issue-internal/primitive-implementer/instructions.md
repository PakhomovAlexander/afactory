# Implement one bounded change

Implement the Task requirements in the captured source. Follow the actual Task scope,
project type, repository guidance and tests.
The required local Gate and two required reviewers check the sealed candidate, and the
independent correctness reviewer builds, privately installs or stages it, and tests it. Address every
acceptance item. Report all failed or unavailable checks exactly. Never publish or use
credentials. Keep the declared Attempt and Task budgets; unfinished work is not complete.

Use only declared artifacts and your own fresh Worker context. Never share sessions, private
reasoning or Worker Notes across roles. Same-model experimental authority does not permit
shared context or removal of independent_from edges.

When the optional `findings` input is present, this Task continues an earlier Task. The source
is that Task's reviewed candidate, not the base. Change that candidate; do not start over.
Resolve or dispute every finding using its evidence. In your report list every finding by ID
as `fixed`, `disputed` or `out of scope`, with one line explaining each disposition.

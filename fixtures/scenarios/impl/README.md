# Configurable impl recipe fixtures

`generate.py` supplies command Workers from the existing native continuation fixture to the public
recipe. Correctness compiles Python source into private bytecode, privately installs it, executes
it and returns exact-Snapshot test evidence. The implementer records the typed findings or admitted
CI evidence it actually receives. These commands are fixtures, not production reviewer advice.

The `alternate` team changes runner arguments and reservations and is natively planned without
execution. `team.example.json` demonstrates caller-owned model, Provider, effort, budget and
independence configuration; its packages receive native digest validation but no model is invoked.
The focused generated recipe lifecycle test uses the inert workspace outcome service, one modeled
PR identity, exact signed local Decisions and a separate human merge flag to cover zero/one/two
repairs. The native continuation test executes findings delivery with these command Workers.
No adapter or private runtime operation is installed by the recipe.

Run the generated recipe tests and the separate installed production adapter regression with:

```sh
cargo test --locked -p af --test it generated_impl
cargo test --locked -p af --test it production_workspace_scenario_repairs_same_pr_and_cleans_only_after_merge
```

`production_workspace_scenario_repairs_same_pr_and_cleans_only_after_merge` uses the reusable
capabilities directly, privately installs the production adapter and native executable, and runs
real accepted Tasks and signed Decisions against real Git commits, worktrees and bare remote refs.
Only external HTTPS/GitHub transport is mocked. It checks ready/pending/stale CI and a fresh repair
updating the same PR after a second signature, then actual merge before owned cleanup. The inert
outcome fixture alone does not prove this production composition.

See [usage](../../../docs/scenario-impl.md) and
[generic capability coverage](../../../docs/scenario-git-workspace.md#recovery-and-bounds) for
transport/recovery and dirty/foreign cleanup refusals. These tests use no live services or models.

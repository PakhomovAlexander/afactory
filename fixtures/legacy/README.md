# Frozen legacy review bundles — private, per-hub

This directory holds frozen `/self-review-heavy` bundles: real reviewer output captured
from real runs, used as the acceptance corpus for the kernel's contracts
(`crates/review-core/tests/legacy_corpus.rs`) and the ledger importer
(`crates/review-store/tests/legacy_ledgers.rs`).

**The template ships none.** A review bundle contains real findings about real code —
private project data that must not travel with a public template. The tests that read
this directory skip with a notice when it is empty; they run for real only in a hub that
has captured its own corpus.

## Capturing a corpus in your hub

1. Run `/self-review-heavy` (or the legacy scripts) on a substantial change.
2. Freeze the bundle produced by
   `.agents/skills/self-review-heavy/scripts/bundle.sh` into a subdirectory here —
   verbatim, never edited. A fixture that has been "fixed" proves nothing.
3. Record integrity: `shasum -c SHA256SUMS` from this directory; regenerate `SHA256SUMS`
   when adding a bundle.

The synthetic corpus under `../synthetic/` (generated by running the real harness on
constructed cases) and the adversarial specs under `../adversarial/` ship with the
template and carry the behavioral coverage; this directory adds real-output acceptance
on top when you have it.

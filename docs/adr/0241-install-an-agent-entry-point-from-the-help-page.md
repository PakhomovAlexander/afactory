# ADR-0241: Install an agent entry point from the help page

**Status:** accepted (2026-10-27).

## Context

`af help agents` describes the Task loop, but a coding agent starting in a repository may not
find it. An `AGENTS.md` pointer and the two common agent skill locations make that entry point
visible. Onboarding cannot silently add files outside `.af/` (ADR-0032).

## Options considered

- Put the pointer in `.af/README.md`: an agent must already have found `.af/` to read it.
- Write agent files during `af onboard --apply`: this makes an unrelated repository edit as a
  side effect of generating review authority.
- Maintain separate copies of the pointer and each skill: those copies can drift.

## Decision

`af setup agents` previews the exact `AGENTS.md` and skill content without writing or spending
tokens. `--write` is the only write action. It works at the root of any Git repository and may
write only `AGENTS.md`, `.claude/skills/af/SKILL.md`, and `.agents/skills/af/SKILL.md`. The pointer
is delimited by `<!-- af-agent-help:start -->` and `<!-- af-agent-help:end -->`. An absent block is
appended without changing existing text; one valid marked block is replaced when its content
differs. A repeated write changes no bytes. Incomplete or repeated markers are refused. An
existing skill is updated only when it matches the current generated bytes or carries an intact
af-generated digest marker over its complete prior content. An edited or foreign skill is refused
before any write. Symlinked target paths are refused.

The pointer is extracted from the `af help agents` page; `af help agents --snippet` prints the
same bytes, and both skills embed those bytes. `af onboard` names setup as a separate step and
does not write these files. The page also maps common launcher scripts to existing af commands.

## Consequences

The help page is the source to edit when the pointer changes. The repository keeps control of
its other `AGENTS.md` content and of any skill that af did not generate. A byte-exact drift test
checks the installed files against help.

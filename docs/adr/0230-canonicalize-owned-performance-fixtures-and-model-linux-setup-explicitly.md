# ADR-0230: Canonicalize owned performance fixtures and model Linux setup explicitly

**Status:** accepted (2026-10-26)

## Context

The telemetry-integrated test-class gate exposed independent fixture assumptions on macOS:
its temporary directory can use the `/var` symlink spelling, `/bin/true` is absent, and Python
has no `os.posix_fallocate`. The workflow cleanup stand-in also inherited the local platform
instead of the Linux runner whose mount commands it models. Early refusals hid the intended
cleanup assertions and left diagnostic subtest directories behind after assertion failures.

## Decision

Canonicalize each shared test-owned temporary root immediately after creation, before strict
admission sees it. Do not resolve arbitrary admitted paths or change production traversal.
Exercise canonical and symlink-parent temporary roots, plus unchanged refusal of fixture links.
Use the current Python interpreter explicitly for no-op child fixtures; retain absolute
execution deadlines and late-exit assertions.

The build-log test retains native `posix_fallocate` when available. On hosts without it, a
scoped test adapter writes real dense bytes and checks logical size and allocated blocks.
Both paths retain capped-log overflow and real timer interruption with child settlement.
Allocation failure must prevent subprocess launch. This adapter is fixture setup, not evidence
of Linux filesystem enforcement; production preallocation remains mandatory and unchanged.
The workflow mount stand-in explicitly identifies as Linux, alongside its existing simulated
mount commands. Existing host-platform refusal tests continue to check macOS rejection.

Anchor the terminal stall fixture's simulated clock jump to its recorded API start. A fixed
additive offset counted setup time again and could expire before the intended boundary.
The same absolute deadline, remaining intervals, three-second wall assertion and cleanup
assertions remain; no production allowance changes.

## Consequences

No production admission, allocation, cleanup, ownership, budget, telemetry contract or test
selection changes. The protected harness inventory and staged digest are regenerated by their
generator. Focused macOS fixture checks precede the kernel's full gate and independent reviews;
these checks establish neither live Docker containment nor hosted performance measurements.
